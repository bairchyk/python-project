# Python Project

Проект для работы с банковскими транзакциями.

В проекте реализованы чтение банковских операций из разных форматов файлов, фильтрация и сортировка транзакций, поиск операций по описанию, подсчёт количества операций по категориям и пользовательский интерфейс для объединения всей функциональности.

## Возможности проекта

Проект позволяет:

- считывать банковские операции из JSON-файлов;
- считывать банковские операции из CSV-файлов;
- считывать банковские операции из XLSX-файлов;
- фильтровать операции по статусу;
- сортировать операции по дате;
- фильтровать операции по валюте;
- маскировать номера банковских карт и счетов;
- выполнять поиск операций по описанию;
- подсчитывать количество операций по заданным категориям;
- работать с функциональностью проекта через консольный интерфейс.

## Чтение файлов

Модуль `src.file_reader` содержит функции для чтения банковских операций из CSV- и XLSX-файлов.

### CSV

Функция `read_csv_file` принимает путь к CSV-файлу и возвращает список словарей с транзакциями.

```python
from src.file_reader import read_csv_file

transactions = read_csv_file("transactions.csv")
```

### XLSX

Функция `read_xlsx_file` принимает путь к Excel-файлу и возвращает список словарей с транзакциями.

```python
from src.file_reader import read_xlsx_file

transactions = read_xlsx_file("transactions_excel.xlsx")
```

### JSON

Чтение операций из JSON-файла выполняется функцией `read_json_file` из модуля `src.utils`.

```python
from src.utils import read_json_file

transactions = read_json_file("data/operations.json")
```

## Поиск банковских операций

В модуле `src.search` реализована функция `search_transactions`.

Функция принимает:

- список словарей с банковскими операциями;
- строку для поиска.

Поиск выполняется по полю `description` с использованием библиотеки `re`.

```python
from src.search import search_transactions

result = search_transactions(
    transactions,
    "Перевод"
)
```

Функция возвращает список операций, в описании которых содержится переданная строка.

Поиск выполняется без учёта регистра.

Пример:

```python
transactions = [
    {"description": "Перевод организации"},
    {"description": "Открытие вклада"},
    {"description": "Перевод с карты на карту"},
]

result = search_transactions(
    transactions,
    "перевод"
)
```

Результат:

```python
[
    {"description": "Перевод организации"},
    {"description": "Перевод с карты на карту"},
]
```

## Подсчёт операций по категориям

В модуле `src.search` также реализована функция `count_transactions_by_category`.

Функция принимает:

- список банковских операций;
- список категорий операций.

Подсчёт выполняется на основе поля `description` с использованием `Counter` из модуля `collections`.

```python
from src.search import count_transactions_by_category

categories = [
    "Перевод организации",
    "Перевод с карты на карту",
    "Открытие вклада",
]

result = count_transactions_by_category(
    transactions,
    categories
)
```

Результат имеет вид:

```python
{
    "Перевод организации": 2,
    "Перевод с карты на карту": 10,
    "Открытие вклада": 4,
}
```

Если операций определённой категории нет, функция возвращает для неё значение `0`.

## Обработка банковских операций

Модуль `src.processing` содержит функции для обработки списка транзакций.

В проекте реализованы:

- фильтрация по статусу операции;
- сортировка операций по дате.

Например:

```python
from src.processing import filter_by_state

executed_transactions = filter_by_state(
    transactions,
    "EXECUTED"
)
```

## Маскирование данных

Модуль `src.masks` содержит функции для маскирования номеров банковских карт и счетов.

Пример номера карты:

```text
Visa Platinum 7000 79** **** 6361
```

Пример номера счёта:

```text
Счет **4305
```

Модуль `src.widget` использует эти функции для подготовки банковских данных к отображению.

## Основная программа

В корневом модуле `main.py` реализована функция `main`, которая объединяет функциональность проекта и предоставляет пользователю консольный интерфейс.

Для запуска программы:

```bash
python main.py
```

После запуска пользователь может выбрать источник данных:

```text
1. Получить информацию о транзакциях из JSON-файла
2. Получить информацию о транзакциях из CSV-файла
3. Получить информацию о транзакциях из XLSX-файла
```

После загрузки операций программа позволяет:

- выбрать статус операций;
- отфильтровать операции по статусу;
- отсортировать операции по дате;
- вывести только рублевые транзакции;
- выполнить поиск по слову или строке в описании;
- вывести итоговый список транзакций.

Пример работы:

```text
Привет! Добро пожаловать в программу работы с банковскими транзакциями.

Выберите необходимый пункт меню:
1. Получить информацию о транзакциях из JSON-файла
2. Получить информацию о транзакциях из CSV-файла
3. Получить информацию о транзакциях из XLSX-файла

Ваш выбор: 2
```

## Установка проекта

Для управления зависимостями используется Poetry.

Установить зависимости:

```bash
poetry install
```

Активировать виртуальное окружение:

```bash
poetry shell
```

Либо запускать команды через:

```bash
poetry run
```
